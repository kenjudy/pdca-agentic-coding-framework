# Tutorial: ACT Phase (Optional)

**If tutorial mode is on** (see `tutorial-setup.md`), open your first reply in this phase with
the line `Tutorial mode: on (ACT)`, then weave in — briefly, don't pad the actual ACT output — what
follows. This is first-reply-only: don't repeat it on every turn within the same phase.

**What this phase is:** a short, human-facilitated retrospective — what worked, what didn't,
1-3 concrete changes for next time. This phase is interactive; it is not run autonomously.

**How to use it:** answer honestly, even briefly. The point is continuous improvement of your
own working agreements and prompts, not a report for someone else to read.

**What's next:** this is the end of one PDCA cycle. When you're ready to start the next piece
of work, open PLAN again with `/pdca:plan` (marketplace install), `/pdca-plan` (manual
install), or `@pdca-framework` (claude.ai/Codex).
